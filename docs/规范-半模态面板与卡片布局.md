## 一句话铁律

半模态 = 声明式 `bindSheet` **挂非槽内的最近可达根**（判据三条见 §1） + `HdsNavigation`
MODAL 壳 + `sheetTitleBarOptions`（KimiSheetCommon 随迁版一字同源，**勿另写/勿自绘标题**） +
**面板内容容器不设左右边距**。

## 1. 壳与标题栏

- **挂点**：`bindSheet` 声明式挂**非槽内的最近可达根**——页面根优先，分支根/面板根/卡片根
  均可，按下列三条判据；关闭走 `onWillDismiss` 动画前同步收口（坑73，勿用 onDisappear
  迟到回调）。
  1. **合法树内**：宿主在合法页面树内——不进 dshinhm 坑64 那类失效槽（`HdsNavDestination` +
     另一套 `PageShell` 的 `@BuilderParam` 内容槽，官方至今未解释根因）。本项目自研
     `PageShell` 未见此病：8 个在役站点全落在此类树内且真机可用。
  2. **存活期不因数据销毁**：宿主在页面存活期内不因数据变化销毁——不在 `ForEach` 行内、
     不做条件销毁；宿主在 `if` 分支里时，须确认切分支时面板已关（本项目面板为全屏遮罩，
     切页签必先关面板，故合规）。
  3. **状态与触发键同位**：`isShow` 状态与触发键同组件位（就近持有）——免跨组件通道，也是
     坑16 家族（`@BuilderParam` 内容槽值参快照 / `@Prop` 首帧冻结）的结构性规避。
- **为什么不是「必须挂页面根」**：面板的**呈现层**（遮罩/停靠位/拖拽条/关闭键/动画）由
  `sheetPanelOptions` 交框架在**窗口层**绘制，与锚点层级无关；锚点只决定**状态归属**与
  **上下文合法性**（内容层在页面树内——§1 深浅色即切即变、§2 `clip(false)` 才可被标题栏
  模糊采样，两处都是实证）。故三级挂点的观感与行为一致。硬写「挂页面根」会把 4 处既有
  真机验证过的写法判违规，并逼着把状态搬离数据（倒挂）。**危**：唯一真实软肋是判据二——
  若将来把触发键放进 `ForEach` 行（如每行都挂模板键），行重建会连带收起面板，届时按判据二
  上提挂点即可。
- 壳 = `HdsNavigation` + `.titleBar(sheetTitleBarOptions(主标题, 副标题, onClose,
  immersiveLevel, otherLevel))` + `.titleMode(MODAL)` + `.hideBackButton(true)` +
  `.bindToScrollable([scroller])` + `.ignoreLayoutSafeArea(SYSTEM, BOTTOM)`。
- `sheetTitleBarOptions` = 主副标题粗体左对齐 + xmark 圆钮关闭 + AUTO 分割线 +
  **静止渐变模糊** + 标题栏 HDS 材质随「其他控件」档位（「无」档透明圆底）——全部官方
  接管；**禁止自绘标题区**（旧项目十二改~十四改教训）。
- 深浅色/材质随动：声明式面板内容属页面树（@StorageProp 驱动重建）——旧项目坑75
  「打开时快照」只发生在编程式 `ComponentContent` 全局 @Builder，不适用声明式；
  **编程式面板不得走本样式**（坑69 同源）。
- **★ 关闭路径与确认（2026-09-23「半模态关闭路径与确认」方案执行笔；新码硬约束）**：
  半模态的关闭意图有**三路**，官方只把其中一路收进漏斗——
  1. **框架级（接线一次全覆盖）**：下拉 / 侧滑返回 / 三键 back / ESC / 点蒙层（以及半模态
     自带关闭键）都经 `onWillDismiss` 转交开发者裁决。依据 = 官方《绑定半模态页面
     （bindSheet）》「二次确认能力」节原文：「声明 onWillDismiss 接口后，半模态页面的所有
     关闭操作，包括侧滑、点击关闭按钮、点击蒙层和下拉关闭，都需通过调用 dismiss 方法来实现。
     若未实现此逻辑，半模态页面将无法响应上述关闭操作。」（★ 2026-09-23 自检轮订正：原记
     「官方《半模态转场》：注册回调后不再立即关闭，由开发者在回调内按 `DismissReason` 决定
     是否关」——**文档名与机制表述都不准**：该节在《绑定半模态页面（bindSheet）》而非《半模态
     转场》；「不调 `dismiss()` 就关不掉」是回调注册后的默认裁决，不是靠读 reason 判的）。
     前提是**已挂该回调**——本仓 `sheetPanelOptions` 在需要收口的站点传第一参。
  2. **纪律级（框架不保，必须手动接）**：标题栏自绘 xmark 的 lambda、面板内容件自身的关闭键
     上行。成因 = 本仓按 HDS 官方建议 `showClose: false` + 标题栏自绘关闭键 ⇒
     `DismissReason.CLOSE_BUTTON` **恒不产生**，而自绘 key 是普通按钮、**不进漏斗**——漏接
     只在真机上表现为「某个关闭方式没弹确认」，编译与静态检查都不会报。
  ⇒ **硬约束（新码）**：每个宿主提供**一个关闭入口方法** `requestClose<域>()`（轻量站点 =
     宿主内私有方法；有域件的站点交域件——先例 `ChatCompressCtrl.requestClose`），
     **标题栏键与 `onWillDismiss` 两路都调它**，方法内决定「直接关 / 先确认」；面板内容件的
     关闭键同路上行到它。存量站点按「**动到哪个在哪个收口**」渐进（不发起一次性全量重构）。
  - **该不该加确认（三门槛同时成立才加）**：①有暂存（用户已投入、未落库：勾选 / 文本 /
    生成物）②丢失有代价（丢了要重做，不是再点一下就有）③已挂 `onWillDismiss`（漏斗在位）。
    **且只在脏态弹**——无变更直接关，「点进去看一眼就退出」零摩擦。**脏态判据必须现读生效
    值**、禁用打开时快照（面板内「恢复默认」会即时改写生效值 ⇒ 快照误报成有改动）。反面：
    关闭即回写的（草稿实时上行）、点一下就落库的、纯信息展示的——一律不加。
  - **确认弹窗形制单源 = `KimiSheetCommon.confirmSheetClose(ui, SheetCloseConfirm)`**：
    站点只供四字段文案（title / message / cancelLabel / confirmLabel）；键序 `[取消, 确认]`
    （确认在右）、取消键 `font_secondary`、确认键 `font_primary`、**仅 `choice.index === 1`
    放行**、**`catch` 一律 `return false`**（弹窗异常不放行关闭——宁可不关、不可误弃）。
    三种「非确认出口」（点蒙层关掉弹窗 / 弹窗期间按系统返回 / 弹窗自身异常）全部落「不关
    面板」；**勿加 `autoCancel: false`**——那会把「点蒙层关弹窗」这条出口变成无出口的死结。
  - **必须不经确认的关闭（负面清单）**：保存键 / 保存勾 / 采用键 / 发送键等**程序化关闭**
    一律直接置状态位（用户意图已明确、落库后无损失可谈）。口诀：**用户主动离开 → 确认；
    流程自己收尾 → 直接关**。
  - 在役确认站点（2026-09-23）：上下文压缩预览（在途生成 / 未采用草稿，先例）、获取模型
    （勾选脏态）、提示词编辑（文本脏态，七槽共用）。

## 2. 动态模糊生效前提（2026-08-30 真机实锤）

- 滚动容器（Scroll/List）必须 **`.clip(false)`**——滚动内容穿透标题栏背后，
  GRADIENT_BLUR 才有内容可透；**缺省裁剪 = 模糊空转**（真机观感「顶部没渐变模糊」）。
- List 配套：scroller 经 bindToScrollable 绑定 + `.scrollBar(BarState.Off)` +
  `.edgeEffect(Spring, alwaysEnabled)`；底部安全区让位 = 尾部透明 `Row` 占位
  （Blank 在 ListItem 下编译 10905201，用 Row）。
- **★ 底部吸底键条（2026-09-18 吸底键笔定稿；先例 = KimiFullInputSheet「保存/发送」、
  MessageCopySheet「复制全文」）**：`Stack({ alignContent: Alignment.Bottom })` 叠三层——
  ①`Scroll` 铺满（`.width('100%').height('100%')`，`clip(false)` 照旧供标题栏模糊采样）；
  ②底部渐变蒙层（`pageBgFade`→`app.color.page_bg` 上透下实、深浅分治，
  `hitTestBehavior(None)` 不拦滚动与文本长按选择）；③键带（**条透明**——键自身
  `fallbackButton*` 四件套承担实底/光感两态，条不垫底不加材料；条
  `hitTestBehavior(Transparent)` = 条面不阻断下层滚动，键本体响应不衰减——透明条走
  Default 仍拦下层手势 = 09-04 悬浮键死区同族）。**Scroll 尾占位 = 蒙层高（含底部安全区，
  两处同源单常量）**——缺占位则滚到底末行被蒙层最不透明处盖住（KimiFullInputSheet 二一九
  改真机教训「底部不能显示在按钮上」）。键动作若写剪贴板：助手消息走 `withAiContentLabel`
  附显式标识（与退役底栏复制键/渲染器复制回调同口径）。

## 3. 卡片三规格与对齐（一字对照旧项目）

- **面板内容容器不设左右边距**（`Column width('100%')` + alignItems Center）——
  边距由各卡自理，三者同一宽度线：
  - 三格方卡组：`Row({space})` 自带 `.padding({left:16, right:16})`，卡 `layoutWeight(1)`；
  - HDS 列表卡：`HdsListItemCard` 官方宽度语义 = 容器 −32（**勿挂 .width()**）；
  - 回退自制卡：`.width(CARD_PANEL_WIDTH)`（=100%−32）= 与 HDS 卡同宽。
- ⚠️ **双重收窄**：容器带左右 padding 时再用 HDS 卡/CARD_PANEL_WIDTH 会再收 −32
  （ProviderPage 同类坑）——容器无边距是唯一前提。
- 方卡规格（SheetGridOption）：官方 `Button(Normal)` + Column(图标上 24 / 文字下 14) +
  `cardBg` 底 + 圆角 20 + 高 88 + 图标 `icon_primary` + 文字 `cardTitleColor`。
- HDS 列表卡评分：`PrefixIcon` 前缀 + 主副标题 + **`SuffixText` 右侧状态尾词**
  （状态字 `font_tertiary`；警示态 `ohos_id_color_warning`——SheetRunParamCard 先例）；
  `cardHeight: 72` + 圆角 16 + `cardBackgroundColor: cardBg(appColorMode)`。
- 分组标题（「提示词（N）」式）：粗体 15fp + 左缘 16 对卡缘。

## 7. 验收清单（新半模态页面逐项过）

1. `bindSheet` 挂非槽内的最近可达根（判据三条见 §1；页面根 / 分支根·面板根 / 卡片根均可）；
2. HdsNavigation MODAL 壳 + `sheetTitleBarOptions` 同源（不自绘标题）；
3. 滚动容器 `.clip(false)`；
4. 容器不设左右边距 + 方卡组 16 / HDS 卡 −32 / 回退卡 CARD_PANEL_WIDTH；
5. 占位卡官方正色；
6. detents 按第 4 节选型；
7. 卡色/材质由 @StorageProp 驱动（勿按值传全局 @Builder——坑75 姿势）；
8. 新符号已核 resources.txt；
9. **有底部吸底键条的面板**：键不随滚动、内容可滚出键后（蒙层渐隐穿过）、尾占位 =
   蒙层高（含安全区）且与蒙层同源单常量、键带 `Transparent` 蒙层 `None`（§2 第三条）。
10. **关闭前确认（有暂存的面板才做，§1「关闭路径与确认」）**：一个关闭入口方法
   （`requestClose<域>()`）+ 标题栏键与 `onWillDismiss` **两路同调** + 脏态判据**现读生效值**
   （非快照）+ 确认弹窗走 `confirmSheetClose`（勿自写键序与键色、勿加 `autoCancel: false`）；
   程序化关闭（保存/采用/发送）**不接**该入口。
