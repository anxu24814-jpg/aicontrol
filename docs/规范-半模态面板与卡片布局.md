## 一句话铁律

半模态 = 声明式 `bindSheet` **挂非槽内的最近可达根**（判据三条见 §1） + `HdsNavigation`
MODAL 壳 + `sheetTitleBarOptions`（KimiSheetCommon 随迁版一字同源，**勿另写/勿自绘标题**） +
**面板内容容器不设左右边距**。面板内需要进下一层时 = 官方 Navigation 栈（§1「面板内层级」条）。

## 1. 壳与标题栏

- **挂点**：`bindSheet` 声明式挂**非槽内的最近可达根**——页面根优先，分支根/面板根/卡片根
  均可，按下列三条判据；关闭走 `onWillDismiss` 动画前同步收口（坑73，勿用 onDisappear
  迟到回调）。
  1. **合法树内**：宿主在合法页面树内——不进 dshinhm 坑64 那类失效槽（`HdsNavDestination` +
     另一套 `PageShell` 的 `@BuilderParam` 内容槽，官方至今未解释根因）。本项目自研
     `PageShell` 未见此病：8 个在役站点全落在此类树内且真机可用。
  2. **存活期不因数据销毁**：宿主在页面存活期内不因数据变化销毁——不在 `ForEach` 行内、
     不做条件销毁；宿主在 `if` 分支里时，须确认切分支时面板已关（本项目面板为全屏遮罩，
     切页签必先关面板，故合规）。
  3. **状态与触发键同位**：`isShow` 状态与触发键同组件位（就近持有）——免跨组件通道，也是
     坑16 家族（`@BuilderParam` 内容槽值参快照 / `@Prop` 首帧冻结）的结构性规避。
- **为什么不是「必须挂页面根」**：面板的**呈现层**（遮罩/停靠位/拖拽条/关闭键/动画）由
  `sheetPanelOptions` 交框架在**窗口层**绘制，与锚点层级无关；锚点只决定**状态归属**与
  **上下文合法性**（内容层在页面树内——§1 深浅色即切即变、§2 `clip(false)` 才可被标题栏
  模糊采样，两处都是实证）。故三级挂点的观感与行为一致。硬写「挂页面根」会把 4 处既有
  真机验证过的写法判违规，并逼着把状态搬离数据（倒挂）。**危**：唯一真实软肋是判据二——
  若将来把触发键放进 `ForEach` 行（如每行都挂模板键），行重建会连带收起面板，届时按判据二
  上提挂点即可。
- 壳 = `HdsNavigation` + `.titleBar(sheetTitleBarOptions(主标题, 副标题, onClose,
  immersiveLevel, confirmAction?, menuOverride?, bottomBuilder?))` + `.titleMode(MODAL)` +
  `.hideBackButton(true)` + `.bindToScrollable([scroller])` +
  `.ignoreLayoutSafeArea(SYSTEM, BOTTOM)`。第 7 参 `bottomBuilder` = 标题栏下方自定义区
  （2026-10-31 搜索吸顶笔起用于面板内搜索框，见 §2）。
- `sheetTitleBarOptions` = 主副标题粗体左对齐 + xmark 圆钮关闭 + AUTO 分割线 +
  **静止渐变模糊** + 标题栏 HDS 材质（随沉浸光感总档，现行恒强档 EXQUISITE；「无」档
  不设材质 + 透明圆底）+ **背板恒透明**——全部官方接管；**禁止自绘标题区**（旧项目
  十二改~十四改教训）。
  **★ 2026-10-29 背板恒透明笔**（决明反馈「很多半模态顶部模糊区感觉有白色蒙层，部分场景
  不好看」→ 拍板「删蒙层、不删模糊」）：原高档分支不设 `backgroundColor`，命中官方默认
  规则（`GRADIENT_BLUR` + 已配置材质 + `enableScrollEffect:false` ⇒ 背板默认
  `sys.color.comp_background_gray` 不透明浅灰白、`blurRadius` 默认 12）= **白蒙层本体**，
  模糊只贡献「糊」不贡献「白」；现两档统一 `Color.Transparent`，与页面级标题栏
  `hdsTitleBarOptions` 同形。顶部自此只剩「面板底材质 + 标题栏材质 + 模糊」三层。
  **模糊不许删**（旧项目沿袭硬要求，见 `ChatPromptSheet` 头注释）。回退阶梯 = ①`blurRadius`
  调 8~10 → ②标题栏材质收一档 GENTLE → ③极淡半透明背板（须手写 alpha 色、深浅两套）；
  `maskExtraHeight` 恒 0（官方默认 32vp 蒙层下探盖首卡上沿），透明后如需软化下沿边界
  只可试 8~16，禁回 32。防回退钉 = `assert-ui-shape` 489 组。
  **★ 已退役形态：标题栏右上两键合并胶囊（2026-10-17 当日立、当日退役）**——官方 menu 数组
  每项只能渲染独立圆钮、无自定义 builder 位，两键合并只能走 `stackBuilder`；排队面板曾按此
  实现（`ChatQueueSheet.QueueTitleBar`，92×40 共用件胶囊），**真机观感不理想**：
  ①与 MODAL 标题行不平齐（背板 = 上留白 8 + 标题行，自绘层在整块背板里居中 ⇒ 中心差 4vp，
  补 `top 8` 可校，但成立前提依赖「自定义层含上留白」这一未文档化假设）；②合并壳体在
  半模态标题栏里与官方圆钮圆底的观感割裂。**结论 = 半模态标题栏用官方 menu 数组，禁自绘
  覆盖层**（页面级标题栏的 `stackBuilder` 覆盖层用法不受影响，见《行内按钮与光感》§4）。
  `ChatQueueSheet` 现形 = 官方双圆钮（数组序 `[trash, play|pause]` 自右缘排布 ⇒ 视觉左
  启动/暂停、右清空；`isEnabled` 空队列双禁用）；`sheetTitleBarOptions` 第 6 参
  `menuOverride` 承接整段菜单内容（无 xmark，关闭 = 下拉手势）。若将来确需合并形态，
  须重新立项并按「例外」逐条真机验收，禁凭本节历史直接回填。
- 深浅色/材质随动：声明式面板内容属页面树（@StorageProp 驱动重建）——旧项目坑75
  「打开时快照」只发生在编程式 `ComponentContent` 全局 @Builder，不适用声明式；
  **编程式面板不得走本样式**（坑69 同源）。
- **★ 关闭路径与确认（2026-09-23「半模态关闭路径与确认」方案执行笔；新码硬约束）**：
  半模态的关闭意图有**三路**，官方只把其中一路收进漏斗——
  1. **框架级（接线一次全覆盖）**：下拉 / 侧滑返回 / 三键 back / ESC / 点蒙层（以及半模态
     自带关闭键）都经 `onWillDismiss` 转交开发者裁决。依据 = 官方《绑定半模态页面
     （bindSheet）》「二次确认能力」节原文：「声明 onWillDismiss 接口后，半模态页面的所有
     关闭操作，包括侧滑、点击关闭按钮、点击蒙层和下拉关闭，都需通过调用 dismiss 方法来实现。
     若未实现此逻辑，半模态页面将无法响应上述关闭操作。」（★ 2026-09-23 自检轮订正：原记
     「官方《半模态转场》：注册回调后不再立即关闭，由开发者在回调内按 `DismissReason` 决定
     是否关」——**文档名与机制表述都不准**：该节在《绑定半模态页面（bindSheet）》而非《半模态
     转场》；「不调 `dismiss()` 就关不掉」是回调注册后的默认裁决，不是靠读 reason 判的）。
     前提是**已挂该回调**——本仓 `sheetPanelOptions` 在需要收口的站点传第一参。
  2. **纪律级（框架不保，必须手动接）**：标题栏自绘 xmark 的 lambda、面板内容件自身的关闭键
     上行。成因 = 本仓按 HDS 官方建议 `showClose: false` + 标题栏自绘关闭键 ⇒
     `DismissReason.CLOSE_BUTTON` **恒不产生**，而自绘 key 是普通按钮、**不进漏斗**——漏接
     只在真机上表现为「某个关闭方式没弹确认」，编译与静态检查都不会报。
  ⇒ **硬约束（2026-10-04 全仓统一笔起全 14 挂载点一体收口；新码同标准）**：每个宿主提供
     **一个关闭入口方法**（零暂存站点 = 回调内直写关闭位或薄收口方法；确认站点 =
     `requestClose<域>(action?)` 单源——先例 `ChatCompressCtrl.requestClose`），
     **标题栏键与 `onWillDismiss` 两路都调它**：手势路带 `action` 进来——放行时
     `action.dismiss()`；自绘键 / 程序化路（保存 / 采用 / 点选）不带 `action`——直写可见性
     状态位；面板内容件的关闭键同路上行到它。
  - **★ 关闭链三件（2026-10-04 全仓统一笔；新码硬约束）**：
    ① **可见性 = 独立 `@State` 布尔挂 `$$` 双向**（程序化关闭 = 赋 false；弃
    「sheetKind !== 'none'」类单向表达式——官方示例唯一形态）；② **`onWillDismiss` 回调内
    放行**——零暂存站点恒放行（`action.dismiss()` 前置），确认站点确认通过才放行
    （`dismiss()` 挪进收口分支按结果条件调用；确认未过不调不放行 = 面板保持打开）；
    ③ **关闭恒不复位内容形态**——关闭写点只置可见性，内容形态串留给下次开启改写（关闭动画期
    内容树恒在，防「关闭瞬间内容抽空 / 切树闪动」）。样板 = 工作区管理页两面板（一千三百
    六十一节修复笔首验）与本次统一后的各站点；对话页面板开关与手势关闭路由域单源 =
    `ChatSheetCtrl.ets`（开关写序 / 手势路由 / 压缩条件放行）。
  - **★ 关闭-再开协调（2026-10-07 全站推广笔；新码硬约束——新挂载点随建随落）**：关闭
    （xmark / 手势 / 程序化）后**离场动效在途期内**再从任一入口开启，直接写下的可见性
    `true` 会被吞或被框架收尾回写压回（症状 = 新面板闪现后立即被收起；官方口径「离场动效
    不支持打断……需要等动效完全结束后，才可以再次拉起」）——在途期**只记开意图、不写
    可见性**，等动效结束再补开。五件式（全站在役挂载点逐字同律；先例 = 会话轨迹页 / 请求
    日志页）：
    ① 可见性 `@State` 声明挂 `@Watch('onSheetVisibleChanged')`（收尾回写兜底入口）；
    ② `sheetClosing` 离场在途位 + 开意图位（两先例站点 = 意图载荷——点行即记、用户关闭先清；
       其余站点 = `pendingOpen` 布尔）；
    ③ `requestOpen`（在途挂起 / 否则即开）→ `applyOpen` 单入口——**全文件唯一写可见性
       `true` 处**（有内容快照的面板在此一并落内容）；
    ④ `onSheetGone` 按开意图补开——接线 = `sheetPanelOptions` **第四参** `onDisappear`
       （d.ts「动画结束后回调」；共用件一处声明，各站点传 `(): void => { this.onSheetGone(); }`）；
    ⑤ 关闭单入口（上方「一个关闭入口方法」同源）**先清开意图 → 置在途位 → 再写可见性**
       （序不可倒置：先写 false 会让兜底补开误触）。
    兜底 `onSheetVisibleChanged` 按开意图补一次（`applyOpen` 内以意图位判空自守；用户关闭已清
    意图故不误触）；`requestOpen` 在途挂起**不加超时兜底**（零冗余等待；`onDisappear` 为 d.ts
    契约回调）。实现全解 = 变更记录一千四百六十五（两先例）/ 一千四百六十六（全站推广）；
    守钉 = `assert-ui-shape.mjs` 329 组（全站点注册表逐站七件性质判定）。

## 2. 动态模糊生效前提（2026-08-30 真机实锤）

- 滚动容器（Scroll/List）必须 **`.clip(false)`**——滚动内容穿透标题栏背后，
  GRADIENT_BLUR 才有内容可透；**缺省裁剪 = 模糊空转**（真机观感「顶部没渐变模糊」）。
- List 配套：scroller 经 bindToScrollable 绑定 + `.scrollBar(BarState.Off)` +
  `.edgeEffect(Spring, alwaysEnabled)`；底部安全区让位 = 尾部透明 `Row` 占位
  （Blank 在 ListItem 下编译 10905201，用 Row）。
- **★ 标题栏下方搜索带（2026-10-31 搜索吸顶笔定稿；先例 = 页面 `SearchTopBand`）**：面板内
  常显实时过滤框经 `sheetTitleBarOptions` 第 7 参 `bottomBuilder` 挂**标题栏下方带**、吸顶不随
  列表滚走（决明「合入标题自定义区吸顶，类似会话提示词页」；官方《设置自定义区域》导语明示
  用途 = 标题下方区域加搜索框）。带属标题栏自身 ⇒ 模糊/材质/滚动感知三件原样，滚动内容仍经
  `clip(false)` 穿透到带下。**内容区固定块仍禁**——它把 Scroll 起点顶下去，标题栏背后永远无
  内容可采样 = 模糊空转（本条原判据不变，别把带理解成固定块）。带高 = `segmentBandParams`
  （下移 8 + 40 = 48，单源勿另算）；内容零手算让位（壳恒 `enableComponentSafeArea: true`，
  带高自动并入组件安全区）；子态无筛选框时传 `undefined` 收带（禁留空带占高）。承载件 =
  `SearchTopBand`（四库页同件，REGULAR 恒光感）。
- **★ 底部吸底键条（2026-09-18 吸底键笔定稿；先例 = KimiFullInputSheet「保存/发送」、
  MessageCopySheet「复制全文」）**：`Stack({ alignContent: Alignment.Bottom })` 叠三层——
  ①`Scroll` 铺满（`.width('100%').height('100%')`，`clip(false)` 照旧供标题栏模糊采样）；
  ②底部渐变蒙层（`pageBgFade`→`app.color.page_bg` 上透下实、深浅分治，
  `hitTestBehavior(None)` 不拦滚动与文本长按选择）；③键带（**条透明**——键自身
  `fallbackButton*` 四件套承担实底/光感两态，条不垫底不加材料；条
  `hitTestBehavior(Transparent)` = 条面不阻断下层滚动，键本体响应不衰减——透明条走
  Default 仍拦下层手势 = 09-04 悬浮键死区同族）。**Scroll 尾占位 = 蒙层高（含底部安全区，
  两处同源单常量）**——缺占位则滚到底末行被蒙层最不透明处盖住（KimiFullInputSheet 二一九
  改真机教训「底部不能显示在按钮上」）。键动作若写剪贴板：助手消息走 `withAiContentLabel`
  附显式标识（与底栏复制键/渲染器复制回调同口径；底栏键 2026-10-12 决明指令复位）。
- **★ 标题栏不接滚动收带 / 模糊降级判据（2026-11-05 立）**：半模态只把
  `bindToScrollable` 用作**滚动感知**（渐变模糊采样、AUTO 分割线跟手），**禁接
  `dynamicHideTitleBar` 收带**——标题栏高度恒定、关闭键恒可见，收带无收益且会挡关闭路径。
  `sheetTitleBarOptions` 与页面级同走官方默认 `BlurStrategy.ADAPTIVE`（两处单源显式固化，零
  行为变化）：快速滚动时系统可临时关模糊保帧率、停止后恢复，属官方默认策略，**不作缺陷
  立项**；半模态恒 `enableComponentSafeArea: true`（内容避让标题栏、不穿透），模糊背后是
  面板底而非滚动内容，故降级几乎无感，**不跟页面级 A 档分档**。三档分档与验收判据 =
  `docs/规范-搜索交互.md` §6。

## 3. 卡片三规格与对齐（一字对照旧项目）

- **面板内容容器不设左右边距**（`Column width('100%')` + alignItems Center）——
  边距由各卡自理，二者同一宽度线（★ 2026-10-31 拍板：HDS 自 API 20 起系统内置、本项目
  compatibleSdkVersion 26 ≥ 20、canIUse 恒真，「无 HDS 回退自制卡」双分支契约已撤，官方
  Hds 卡为唯一形态）：
  - 三格方卡组：`Row({space})` 自带 `.padding({left:16, right:16})`，卡 `layoutWeight(1)`；
  - HDS 列表卡：`HdsListItemCard` 官方宽度语义 = 容器 −32（**勿挂 .width()**），宽度线唯一。
- ⚠️ **双重收窄**：容器带左右 padding 时再用 HDS 卡或 `CARD_PANEL_WIDTH` 定宽自制卡会再收
  −32（ProviderPage 同类坑）——容器无边距是唯一前提。`CARD_PANEL_WIDTH` 常量不随回退
  撤除退役（2026-10-31 拍板只删面板内回退卡用途），仍是不走 `HdsListItemCard` 的自制卡
  宽度基准（单开关卡等非回退消费方在役）。
- 方卡规格（SheetGridOption）：官方 `Button(Normal)` + Column(图标上 24 / 文字下 14) +
  `cardBg` 底 + 圆角 20 + 高 88 + 图标 `icon_primary` + 文字 `cardTitleColor`。
- HDS 列表卡评分：`PrefixIcon` 前缀 + 主副标题 + **`SuffixText` 右侧状态尾词**

  `cardHeight: 72` + 圆角 CARD_RADIUS（20）+ `cardBackgroundColor: cardBg(appColorMode)`。
