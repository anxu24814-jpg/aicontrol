### 1.1 组卡与单卡形态区分（2026-09-08 沉淀——「何时组卡何时单卡」选型判据）

> 背景：偏好设置/更多信息页组卡化（变更记录 130 节）后，工程内组卡与单卡形态并存。
> 本节把选型判据固化为一条规则——防「见卡就合」（不同质硬凑组卡）与「合不动就散」
> （≥2 行同质仍一张一张单卡铺）两个方向跑偏；新增设置类卡片先过本节再动手。

**统一判据 = 先判行形态，再数行数**：

| 形态 | 实现 | 判据 | 工程先例 |
|---|---|---|---|
| 组卡 | GroupSettingCard（≥2 行 items） | 同质行 ≥2，且行能套进组卡行规格（24vp 图标 + 16fp 标题 + 14fp 副标题 + 尾部 Toggle/点击） | 设置页 8 组（卡1/卡3~卡7 各 2 行；卡2 三行 = 系统提示词 + 提示词 + 技能库〔2026-09-13 技能层笔 1 并入〕；★ 2026-09-20 应用内自检退役后共 8 张）；偏好设置聊天交互 4 行/阅读与会话 3 行；更多信息 3 组 × 2 行 |
| 单行组卡 | GroupSettingCard（1 行 items） | 跳转入口「独立成行」——**决明 2026-09-07 分组拍板例外**（独立入口不并组），**不推广为新常态**；★ **第二例外 = 卡级开关行**（2026-09-18 分类卡重组，细则见 §4.4）：一页多卡、每卡恰 1 行「卡名 + 副标题 + 卡级 Toggle」，行规格同 §4.1 开关行 | 设置页卡8（更多信息）〔卡号随 2026-09-12 记忆+主动消息合并卡调整；记忆同日入合并卡退出本形，用量统计 2026-09-10 与费用估计组卡退出本形；★ 2026-09-20 应用内自检全量退役：原列「卡8（自检）/卡9（更多信息）」中的自检卡整块删除，单行组卡自此只剩「更多信息」一张、卡号下移为卡8〕；助手工具页五卡（2026-09-18） |
| 单开关卡 | 自绘卡（cardBg + 圆角 16 + CARD_PANEL_WIDTH + 官方 Toggle 右置，Toggle 可点） | 恰 1 行开关项（标题 + 说明 + Toggle），无组卡行图标规格 | 偏好设置界面观感（页签切换动画）；外观显示「背景仅用于会话页」（自绘卡）；服务商余额开关行（半模态 ListItem 行，同形态无独立卡体） |
| 选择/内容卡 | 自绘卡（标题 + 说明 + 控件） | 控件不是「行」形态——分段选择/滑轨/文本域/多行输入 | 偏好设置加密会话（生物识别分段卡）；系统提示词页内容框与变量区；外观显示滑轨面板 |
| 单条目入口卡 | HdsListItemCard（HDSComponent.Full 门槛；无 HDS 回退自制卡） | 单条「入口/行卡」语境、无组卡语义的通用行卡 | 关于页三卡（AI 声明/开源鸣谢/版本信息）；**存储管理页「会话附件」卡（2026-09-15 附件管理列表笔——置于「可安全清理」卡下方、整卡可点进管理页、副标题不带数字）**；设置搜索页结果与最近使用；会话列表行卡 |
| 列表条目卡 | 自绘卡（`Button(type Normal)` + 内容列 `layoutWeight(1)` + 尾部四点键菜单） | 数据行列表——内容 + 副行 + 行内动作，非设置项、无组卡语义 | 会话提示词库页 `TemplateRow`；记忆页 `MemoryRowCard`（2026-09-08 对齐——同类列表卡形制同源：卡宽 `CARD_PANEL_WIDTH` / 圆角 16 / padding 14 / 标题 15fp Medium / 副行 13fp〔2026-09-12 UI 同形异构归一笔 4：说明小字全应用统一 13fp，原 12fp 退役〕/ 尾部四点键 `dot_grid_2x2` 弹 编辑·删除 菜单） |

**两条硬判据**：
1. **先判形态**：行能套进组卡行规格 = 组卡行；套不进（分段/滑块/文本域/输入）→ 内容卡，
   禁止硬塞组卡（拼不齐的组卡是「凑合」不是整合）；
2. **再数行数**：同质 ≥2 行 → 组卡；恰 1 行 → 按形态选单卡（开关项/内容卡/入口卡）；
   1 行跳转入口 = 默认单条目入口卡（HdsListItemCard），设置页「独立成行」单行组卡是
   登记在案的拍板例外，不扩散；★ 2026-09-18 增**第二例外 = 卡级开关行**（一页多卡各恰
   1 行开关，决明指令定形，见 §4.4）——两条例外均须逐笔登记，不得类推到其他页。

**数据行组卡的行数由数据决定，不换形**（2026-09-09 补，模型选择面板收藏段修复沉淀）：
本节判据管**设置类卡片**的组件选型（组卡 ↔ 单开关卡/内容卡/入口卡）；模型选择面板这类
**数据行组卡**（卡内行 = 数据行，行尾带动作键）行数随过滤结果变化——某服务商在「收藏」分段
只剩 1 行时，渲染的是同一张组卡的**单行退化形态**，不换组件、不换形。理由：①本节三类单卡
都承载不了本面板的行内容（行尾收藏爱心 + 选中打勾 + 左侧整块可点区，`HdsListItemCard`
只承载文本）；②行数会在用户操作中变化（分段内取消收藏 2→1→0），形态跟着变 = 手指下的
布局跳动 + 双代码路径。**判据落点 = 组件选型，不是行数阈值**——数据行组卡恒用同一张卡。

## 2. 官方形态对照（2026-09-07 查证，含未采用项）

官方列表范式的完整骨架 = **List + ListItem + stateStyles(pressed) + List.divider**：
- List.divider({strokeWidth, color, startMargin, endMargin}) 为官方分割线属性；
- ListItem 挂 stateStyles({pressed: {.backgroundColor($r('sys.color.ohos_id_color_click_effect'))}})
  做按压蒙层（系统按压色资源，自动深浅色）；
- List API 参考明示联动细节：「ListItem 设置多态样式时，**被按压的子组件上下的分割线不绘制**」。

当前 Button+Divider 拼装与之的差距 = 该按压分割线联动细节（按压时行上下分割线仍显示，
0.5vp 细线、观感差异极小）；Button stateEffect 按压色同为系统内建自动深浅色，按压色无差距。
**List 骨架不采用（2026-09-07 决明确认口径）**：决定性理由 = 项目滚动容器经验——**页面级
滚动一律 Scroll+Column 优先**，List 在本项目架构（全屏窗口 + 沉浸光感 + HdsNavigation）下
有坑族前科（dshinhm 坑50 一级页 List 顶蒙层点不了滑不动、改 Scroll 根治；坑66 家族视口
裁切；本项目坑9 List padding 视口缩进、坑10 onMove 拖拽裁切），换骨架还需重推全部分割线
缩进口径（startMargin 相对 List 内容区）。List 只保留给确需懒加载的长列表（会话/消息流）。
组卡定稿路线 = 外层 Scroll + 卡内 Column+ForEach（自检报告观察项 O-2 据此闭环为「不采用」）。
**★ 2026-09-11 复踩实锤（余额查询二级页执行笔，决明真机报障「标题栏没接入沉浸光感，内容整体左偏」）**：
该页初版照搬了 List 骨架（顶/底留白走 List padding）——两病齐发：①内容永远滚不进标题栏蒙层，
沉浸光感落空（坑9 原文第一句即此现象）；②`ListItem` 子项不水平居中 `CARD_PANEL_WIDTH` 卡，
整列内容左偏。改 Scroll + Column（留白归内容内 padding）两病同消。**新建表单/设置页一律从
Scroll+Column 起手**；List 只准用于「确需懒加载的长列表」与「已用 `contentStartOffset/EndOffset`
全量偏移轨的老列表页」（服务商/引擎/排序三页先例），且**不要**把 CARD_PANEL_WIDTH 卡直接塞进
ListItem（本实锤的组合是本项目唯一一次，勿再出现）。

## 4. 加卡 Checklist（新增一张组卡 / 组内一行）

组件消费只有设置页先例（SettingsPage.ets settingGroups()），新增步骤按序：

1. **标题常量**：新入口标题在 `common/SettingSearch.ets` 引用既有 SETTING_TITLE_* 常量；
   全新入口先在该文件新增常量（单一来源——页标题栏、搜索注册表、组卡行三处共用）。
2. **行数据**：SettingsPage.settingGroups() 对应组内追加 GroupEntryItem 字面量
   （icon: $r('sys.symbol.*') + label 常量 + secondary 副标题 + onClick 上抛回调）。
   ArkTS 禁 build 内匿名对象字面量数组——必须走类型化返回值方法（10605038 实锤）。
3. **导航回调**：SettingsPage 新增 onOpenXxx 成员（空默认函数），HomeNavigation **两处**
   SettingsPage 实例化都要接线（主路径 + 回退路径——历史上回退路径漏接过，2026-09-06 补齐），
   push 动作进 nav 的 actions 集中处。
4. **分组调整**：新行进既有组 = 组内追加即可（分割线自动生成，末行不显自动维护）；
   新建组 = settingGroups() 追加数组，**组键 = 首行标题**，确认首行标题与其余组不重复。
5. **副标题文案**：动词开头一句功能简介口径（「管理 xx」「查看 xx」），受宪法「面向用户
   文案写作规约」约束（禁冒号分号括号连环）。
6. **帮助中心两问**：新入口在 HELP_GROUPS 是否有对应条目/需新增？既有条目是否过时？
   改 HelpContent.ets 后跑 `node scripts/help-search-check.mjs`。
7. **搜索注册**：新入口可搜则 SettingSearch 注册表加条目（一级行卡入口必搜），跑
   `node scripts/setting-search-check.mjs`；两项均已入 delivery-gate。
8. **记录**：变更记录当日条 + 若分组/行数变化影响帮助文案同步改。

### 4.1 开关行（2026-09-08 偏好设置页组卡化扩展；同日真机报障修订刷新责任 + 决明「统一」定形）

组件消费先例 = 助手工具页（`AssistantToolsPage.cardItems()`——★ 2026-09-18 起卡级开关行；原成员行 `groupRows()` 随成员明细整面退役）与偏好设置页（`PreferencesPage.chatGroup()`/`readGroup()`）——**两页同形态**。

- **行数据**：`GroupEntryItem` 增可选 `toggleValue: () => boolean` + `onToggle: (isOn) => void`（两字段齐全 = 开关行，行尾渲染官方 Toggle；此时 `onClick` 可省）。
- **交互唯一形态 = 只点开关**（2026-09-08 决明拍板「只能通过点击开关控制开闭」，同日由工具页统一到全应用）：Toggle 可点自切换（Default 命中 + `onChange` 上行 = 唯一控制面）；行本身不可点、`.stateEffect(false)` 去按压反馈（避免「按得下去、什么也没发生」）。**无形态开关**——组件行为单一来源，原「纯视觉 Toggle + 整行点击」形制已废。
  - 例外：组头总开关 Toggle 仍恒纯视觉（§4.2/红线 7）——其显示态是派生值，可点会因程序化翻转触发 onChange 反噬全组。★ 2026-09-18 分类卡重组后该形态在工程内暂无消费方（工具页卡级开关走标准开关行，见 §4.4）。
- **显示刷新责任在调用方（2026-09-08 真机报障根因）**：`items` 是普通成员入参——父组件重渲
  不更新它、组件自身又无状态变化 → 组卡 build 不重跑 → 开关 Toggle 定格首帧（症状 = 数据
  已变、计数已变、开关不动，退出重进才对）。调用方须把组卡放进**键含开关态/纪元的 ForEach**
  （规范 §3 主通道「键变重建」）：工具页 = `group.title + '|' + toggleEpoch`（库读回 / 每次
  开关交互含被拦截回弹都自增）；偏好设置页 = 恒单例纪元键 `[chatGroupKey()]`（键含本组各
  开关值）。组件内 ForEach 键含开关值只在组件确实重渲时才起作用，**不能替代调用方键**
  （坑57「普通成员入参不重渲染」+ 坑16 家族；子组件 @Prop 承载同为禁区——PageShell.content
  内 @Prop 不随父状态更新，2026-08-31 实锤）。
- **取数写法**：`toggleValue` 闭包读调用方状态（@StorageLink 或 @State——响应式，键求值时现读）；`onToggle` 闭包写（@StorageLink 写即持久化；工具页 @State 写后落库）——特殊逻辑（智感握姿失败回滚 + toast）在 onToggle 回调内做。
- **已知代价 = 键变重建切换无过渡动画**（重建法同代价；后续如需动画另立调研，勿顺手改）。
- 行高沿用官方分档（有 secondary 64 / 无 56）；分割线/图标/蒙层与跳转行完全一致。

### 4.2 分组折叠列表（2026-09-08 工具页域分组——决明拍板「按域分，组行做总开关」）

★ **2026-09-18 状态变更（分类卡重组笔，变更记录七百一十七节）**：本节形态（组头行 +
折叠 + 展开态成员行）**在助手工具页整面退役**——该页改「分类卡」形态（§4.4），
本节机制因此在工程内**暂无消费方**；下列条目保留为形态存档，**不得据以在工具页实施**
（附件管理页组头折叠是另一形态，见其条）。

先例 = 助手工具页（`AssistantToolsPage`，2026-09-08 域轴两组「基础能力」「设置与配置」→
09-13 语义轴两组「读取类/修改类」→ 09-18 分类卡轴五卡 = 本节形态退役）。适用 = 同一页
条目多且可按域归类的开关列表（组头行给全貌 + 总开关，成员默认收起）。

- **分组元数据单源 = `ToolTypes.ets`**：`ToolEntry.group` 必填字段（新增工具忘标 = 编译期报错）
  + `TOOL_GROUP_ORDER` 组序 + `toolGroups()` 分组视图；页面不写分组映射表。
- **组头行**：卡体（CARD_PANEL_WIDTH + cardBg + 圆角 16 + 高 56）内左右两区——左侧可点区
  （`layoutWeight(1)` + `height('100%')`）承载「折叠箭头 + 域标题 + 已启用计数」，右侧点击区
  内放**纯视觉**官方 Toggle 承担组总开关。**两区并列不嵌套**：左侧区点击 = 展开/收起，右侧
  区点击 = 批量开/关，互不干扰。**计数字样右对齐紧贴总开关左侧**（标题与计数之间 `Blank()`
  撑开）——组标题长度不一时跨组计数仍对齐（2026-09-08 决明指令）。
- **组总开关 Toggle 恒纯视觉（`hitTestBehavior(HitTestMode.None)`，禁挂 onChange）**：总开关
  显示态 = 组内全开，是**派生值**——单行开关一变它就程序化翻转，挂 onChange 会被这次翻转
  反噬成「关一个 → 总开关回调 → 全组关闭」（2026-09-08 决明真机实锤）；点击由右侧区
  `onClick` 承担（值 = `!groupAllOn`，全开态点则全关、否则全开）。配套：单行 `toggleTool`
  加**空转守卫**（组批量落库后成员程序化回调的集合未变 → 跳过重复落库）。
- **折叠 = 条件渲染 + 箭头翻转 + animateTo 切换**：`if` 条件渲染 + 
  `SymbolGlyph(sys.symbol.chevron_down).rotate({ angle: expanded ? 180 : 0 })`；状态翻转包进
  `getUIContext().animateTo({ duration: 300, curve: Curve.EaseInOut }, () => 翻转)`——官方 FAQ
  `faqs-arkui-769`「如何实现简单列表折叠和展开」的两条路查证结论：①TreeView 高级组件（分层
  导航树形态，官方定位侧边导航，与设置卡列表不匹配，不采用）；②基础组件自组合 +
  `UIContext.animateTo`（**本项目采用此路**，时长取官方示例值 300ms；先例 = 价格卡
  `ModelPriceCard` 标题行 / 聊天页工具卡 `ChatMessageItem` 卡体 / 附件管理页组头
  `AttachmentManagePage` 展开折叠两路；原列的「助手工具页组头
  `AssistantToolsPage.toggleGroupExpand`」2026-09-18 随分类卡重组退役）。
  ★ 2026-09-17 折叠动画笔（决明「官方有动画，可加吗」）前，本项目折叠一律无动画；该笔按官方
  示例给两处**卡片类**折叠补动画（价格卡 + 聊天页工具卡），同日统一笔「后两处统一」再补齐
  其余两处组头——**全项目五处折叠点，除聊天页思考块（本有内容盒 / 视窗解耦高度动画）与
  2026-09-18 工具页退役那处外，三处带 animateTo**。★ 附件管理页折叠机制与另两处不同：不是条件渲染而是扁平列表行增删
  （LazyForEach 数据源 `insertRange` / `removeRange`），animateTo 包的是数据变更，展开路
  因异步查库故动画在数据到位后播。★ 官方背景知识（FAQ `faqs-arkui-1400`）明示「同属性动画，
  布局类改变宽高的动画，内容都是直接到终点状态」——条件渲染式折叠的内容不随高度形变；
  要做「内容跟随高度」的平滑收拢须照思考块的内容盒 / 视窗解耦（ChatMessageItem.animateBody，
  2026-09-16 三态收口），复杂折叠再走那条。
- **折叠状态持久化**：默认页面级（`@State`，不持久化）；用户要求「记住收放」时走
  AppPreferences 持久键 + `@StorageLink` 双向绑定（先例 = `prefPriceCardCollapsed` 价格卡收起
  态，2026-09-17 折叠记忆笔）——键须登记备份分域两表之一，随备份与否按「用户设置 / 本机痕迹」
  判据归档。
- **组总开关 = 批量复用单行开关的两道闸**：逐个成员走 `isConsoleExclusive` 反向拦截与
  `isConsoleLocked` 锁定判定，被挡成员保持原状并汇总 toast；落库一次（组外成员原序保留）。
  **禁**为组开关另写一套放行逻辑（两道闸必须与单行同源）。
- **默认态**：成员默认收起（组头计数给全貌）；展开态为页面级 @State，不持久化。
- **展开态 = 一张 GroupSettingCard**（2026-09-08 决明指令「展开后的单卡合并为组卡」）：成员行
  走组卡行规格（24vp 图标 + 16fp 标题 + 14fp **单行**副标题 + 尾部开关，行点击切换）；行副标题
  源 = `ToolEntry.uiDesc`，因此 uiDesc 恒 ≤ 14 字（长句在固定行高里溢出——断言已钉）；图标映射
  在页面（`rowIcon`，符号名对 SDK 符号表核验），注册表不带 UI 资源。

### 4.3 板块头说明气泡（`SectionHeader.hint`，2026-09-08 立——三处全宽提示卡治理沉淀）

- **形制**：板块头标题行 = 标题（`layoutWeight(1)` 撑满剩余宽）+ 行尾 `InfoHintButton` ⓘ
  气泡键——行宽恒 `CARD_PANEL_WIDTH`，键落卡右缘与左端标题左右对称；`hint` 传空 = 不出键
  （存量调用方零观感变化）。实现单源 = `components/SectionHeader.ets`，气泡件单源 =
  `components/InfoHintButton.ets`（禁另起气泡件或自绘弹层）。
- **用法判据**：长说明文字（多句、含边界条件或跨页指引）一律收入板块头气泡，板块面只留
  标题 + 一句副标题。**禁独立全宽说明卡**（卡面只有一段说明文字 = 白占整行高，2026-09-08
  决明三连反馈「两开关下方提示卡是全宽」「整理的卡也是全宽」「暂无记忆提示卡也是全宽」的
  根因）；卡内说明小字仍按宪法「功能设置卡布局次序」条置于操作按钮上方——短句留卡内、
  全文入气泡，两者并存时照外观页光感新规范开关卡（`FallbackSwitchCard`）先例。
- **单键禁独立卡**（2026-09-08 决明「包住立即整理键的卡片内只有该键了，且仍为全宽，优化」
  追认）：**卡内只有一个操作键时不开卡**——键改内容宽（不挂 `width('100%')`）、左对齐挂在

  备份到本机」先例），单键卡与单键通宽按钮同禁。
- **空态与状态提示**：板块级空态用**行内提示行**（13fp `cardDescColor` + `CARD_PANEL_WIDTH`，

  （2026-09-09 增补，记忆页总开关关态
  说明先例）——短句、随状态条件渲染者留在板块内可见（优于藏进气泡），原「独立全宽卡」
  写法即本条治理对象。

### 4.4 分类卡（卡级开关，2026-09-18 分类卡重组笔定形——决明「类似工具就合为一个卡，只保留一个新的主副标题」）

- **由来与适用**：助手工具页（`AssistantToolsPage`，变更记录七百一十七节）——同一页条目多、
  可按用途归类，但用户层**不需要成员明细**。适用 = **同域多项、卡内成员对用户无区分价值**
  的场景（一卡多件、一卡一枚开关、整卡批量进出）；与 §4.2 的区别 = 无组头行、无折叠、
  无成员明细，**卡副标题即全貌**。
- **形制**：每卡恒一张 `GroupSettingCard` 单行开关卡（24vp 图标 + 16fp 卡名 + 14fp 单行副标题
  + 卡级 Toggle），`items` 恒恰 1 项——即 §1.1「单行组卡」的**第二例外（卡级开关行）**，
  须逐笔登记、**不得类推**；Toggle 可点自切换 = 唯一控制面（§4.1 开关行统一形态）。
- **卡级开关语义**：开 = 该卡全部可开成员进启用清单，关 = 整卡退出；逐个走 §4.1/§4.2 同款
  两道闸（`canEnable`/`canDisable` 单源），被挡成员保持原状并**汇总 toast**（**禁**另写一套
  放行逻辑）；批量开的「批后目标集合」两段式复核（同批含从属件时）照 §4.2 组总开关条同源。
- **卡副标题三档**（纯显示态）：①卡内可开件 0 → 报整卡受限（「仅控制台助手可用」）；②含
  依赖件且依赖关闭 → 报依赖拦截（联网总开关）；③常态报功能描述。**单行 ≤14 字**——组卡行
  64vp 固定行高，超长即溢出（断言已钉）。
- **显示刷新**：调用方键变重建（红线 4）——键含**开关纪元** + **依赖总开关态**（后者变化只
  重跑 build、不更新组卡的普通成员入参，故必须进键）。
- **不可逆边界**：卡开关显示态是**派生值**（按清单求值）；压制/受限导致的不可用**不得写回
  启用清单**——放开闸门即回到用户原态。

### 4.5 表单字段标签行（2026-09-23 立——知识库编辑条目页「分不清标题和关键词」回归现场沉淀）

- **由来（回归现场）**：编辑条目页按 §4.3 把卡内说明收进 ⓘ 气泡后，条目卡只剩两个 `TextInput`

  显示，编辑既有条目（两框都填着字）时字段身份无处承载。⇒ **收说明不可连字段身份一起收**。
- **形制（多字段卡）**：每个输入框头顶一个**恒可见标签行**——`Text(标签)` 13fp +

- **占位符写法**：标签已给字段名 ⇒ 占位符只留示例、**禁重复字段名**（`'例如 TCP 三次握手'`，

- **落地清单**（本形制的全部到位点，新增多字段卡照此入门）：`KnowledgeEditPage` 条目卡

## 5. 红线（违者必回归真机复验）

1. **行缩进禁用 margin 写法**：Button/ListItem `width('100%') + 对称 margin` 实测蒙层与卡
   等宽缩进失效（坑23，0bce73d 像素实锤）——一律外包容器 padding 承担，组件头注释有警告。
2. **蒙层圆角与卡圆角两处同改**：GroupSettingCard EntryRow borderRadius 与 build 卡体
   borderRadius 必须同值（dshinhm 一七八改铁律）。
3. **行高固定分档勿改回自适应 padding**：48vp 自适应 = dshinhm 旧规格，2026-09-07 决明
   「纵向宽度偏窄」实锤废弃。
4. **items 普通成员 + 调用方键变重建**：GroupSettingCard.items 为普通成员（组件自身不重渲，
   坑57 家族），仅限静态配置数据；**开关行/动态行数据必须由调用方把组卡放进键含状态/纪元的
   ForEach**（键变重建 = 规范 §3 主通道）——禁改 @Prop 承载（PageShell.content 内 @Prop 下
   发热点，坑16 家族），禁依赖组件内 ForEach 键单独承担跨父状态刷新（2026-09-08 真机报障
   根因：组总开关/单行点击后成员开关定格）。
5. **组卡与单卡区分**（2026-09-08 口径修订，判据细则见 §1.1）：≥2 行同质行 → 组卡；
   恰 1 行 → 单卡——开关项自绘单开关卡 / 选择控件内容卡 / 入口行 HdsListItemCard
   （HDSComponent.Full 门槛）；1 行跳转入口「独立成行」= 设置页决明 2026-09-07 拍板
   登记例外（更多信息；★ 2026-09-20 自检卡退役后仅余这一张），不推广；禁把 1 行开关项或控件硬塞进组卡
   （官方系统设置同口径）。★ 2026-09-09 口径补：例外可被决明指令收回——「数据与同步 +
   存储管理」两单行组卡经决明指令合并为一张双行组卡（同域入口优先成组，§1.1 表组卡行）；
   合并后原例外项从表内退出，不视为对「独立成行」例外本身的否定（2026-09-12「记忆 +
   主动消息」合卡同此口径）。★ 2026-09-18 增**第二例外 = 卡级开关行**（助手工具页一页五卡
   各恰 1 行 Toggle，决明指令定形）——按本条字面读会误判为须转单开关卡，实际登记例外，
   照 §4.4 实施；两条例外均须逐笔登记。
6. **开关行契约**（2026-09-08 立，同日真机报障 + 决明「统一」定形）：**唯一形态 = 只点开关**
   ——Toggle 可点（Default 命中 + onChange 上行 = 唯一控制面），行不可点且 `.stateEffect(false)`
   去按压反馈；无形态开关（组件行为单一来源）。**禁**①行点击同时切换（与 Toggle 双触发）；
   ②@Prop 子组件承载行开关状态（PageShell.content 内 @Prop 下发热点，坑16 家族）；③行点击
   直接操作 Toggle 事件；④给开关行 Toggle 挂 `hitTestBehavior(HitTestMode.None)`（退回纯
   视觉形态 = 开关点不动）。显示刷新恒走调用方键变重建（红线 4）。
7. **分组折叠两区并列**（2026-09-08 立，§4.2 配套）：组头行左侧可点区与右侧 Toggle 必须是
   兄弟节点——禁把 Toggle 放进左侧可点区（点击双触发/误触折叠），禁给左侧区挂
   `hitTestBehavior(HitTestMode.None)`（会连 Toggle 一起吞掉）；**组总开关 Toggle 恒纯视觉、
   禁挂 onChange**（显示态为派生值，单行变动程序化翻转它会反噬成全组关闭——2026-09-08
   真机实锤）；折叠恒走条件渲染 + 箭头翻转 + **animateTo 切换**（2026-09-17 折叠动画笔按
   官方 FAQ faqs-arkui-769 示例落定，见 §4.2 条；本页组头仍无动画——未点名，要加走同一形制）。
   ★ 2026-09-18 分类卡重组后本红线形态在工程内暂无消费方（工具页组头行整面退役）——
   条款保留待复用，勿据以在工具页重建组头。
8. **行内可变长文本必须吃布局权重**（2026-09-23 请求日志页真机报障「日志卡有时标题过长顶出
   右边」立；坑76）：一行 = 左可变长文本 + 右固定数据项（状态 / 时间 / 动作键）时，左文本
   **必须挂 `layoutWeight(1)`**。官方口径（`ts-universal-attributes-size` layoutWeight 段
   原文）：「如果容器中有子组件设置了 layoutWeight 属性，且设置的属性值大于 0，则所有子组件
   不会再基于 flexShrink 和 flexGrow 布局」——非权重子组件先按自然尺寸占位，权重子组件吃满
   主轴剩余空间（忽略自身 width/height，保留 minWidth）。故**只写 `maxLines(1)` +
   `TextOverflow.Ellipsis` 拦不住越界**：每个兄弟各自量到「整行宽」上限，行内依次排布时总和
   仍可超出容器，把右侧数据项挤出卡右缘（坑27 家族）；裸 maxLines 仅在**该文本独占整行**时
   充分（同卡第二行 `方法 + URL` 即此形）。同笔纪律：权重接管后同行 `Blank()` 的 flexGrow
   失效（恒 0 宽，只白占一个 `space` 间隙）——撤除，右推责任移交权重。
