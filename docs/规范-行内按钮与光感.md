## 1. 现行规约速查（四类键形制）

| 键类 | 形制 | 先例 |
|---|---|---|
| 行内图标键（SymbolGlyph 符号键：删除/刷新/更多类） | 无底 `ButtonStyleMode.TEXTUAL` + `font_secondary`（TEXTUAL 自带官方按压变淡反馈）；**禁止垫 `fallbackButton*`/`resolvedButton*` 四件套**（灰实底圆角 = 「圈选圆框」观感，2026-09-04 回退实锤） | ProviderHeadCard 刷新键（arrow_clockwise 16fp，2026-08-30 起） |
| 行内文字键（获取模型/添加/查询/重填/编辑等） | `resolvedButton` 四件套（fontColor/Bg/systemMaterial/stateEffect）；内容区组件走 `fallbackButton*` 双态（见 §3，弹窗/面板豁免区照旧 resolvedButton*） | ProviderModelsPanel 获取模型/添加 |
| 主操作键（「保存」类） | `primary=true` 官方强调蓝 + 恒白字 | AdjustStageView「保存」、DataSyncPage.ActionBtn |
| 选项类 chips（套用模板预设/模型能力多选等） | 是「选项」非功能按钮，不适用按钮条目——Text 胶囊 + badgeBg 灰底 + 无按压光感 | ModelCapsCard |

- **禁自绘红线**（2026-08-30 定稿，历经光感化不变）：禁止自绘 `borderRadius`/`fontSize`/
  `fontColor` 覆盖官方形制；确需自定义（突出主操作等）先拍板。
- 「更多键无圆底」自 2026-08-30 起，与图标键无底化同构。
- **例外（2026-09-07 决明拍板，终版）**：提示词变量插入卡（系统提示词页/助手提示词页变量区）
  ——「点击插入」入口语义，非纯选项，脱离第 4 行豁免，采用**官方胶囊按钮**：
  `.type(ButtonType.Capsule)`（API 18+ 缺省 = ROUNDED_RECTANGLE 大矩形）+ 显式官方灰阶实色
  `app.color.comp_fallback_gray`（与内容区「恢复」键同色，深浅分治不透明）+ 官方原生按压
  （stateEffect 默认 true）+ 显式 padding；**不接沉浸光感**（不叠 systemMaterial——
  Material.empty 属「已配置」触发内容层默认背景 = 双层蒙层）。历轮真机四连实锤：
  ①缺省型 122×40 大矩形灰底（「大矩形灰底蒙层」）；②Material.empty 双层蒙层；
  ③光感态透明底无材质 = 无按钮底（「不开外观回退看不到按钮底」）；④无背景时默认 =
  主按钮强调蓝（「怎么成蓝底的了」）。四连后定稿（本卡只保留淡蓝字色定稿）；
  其余选项类 chips（ModelCapsCard 等）照旧。
- **例外二（2026-08-31 决明拍板，2026-09-17 自检轮登记防误改）**：服务商编辑页模型区
  功能键行的「更多」键（`ProviderModelsPanel` 批量启停菜单键）**恒为圆底样式**——
  `ButtonType.Circle` 40×40 + 官方灰底 + 中心图标 + 按压光感，照标题栏更多按钮。它与
  本档第 1 行「更多类图标键无底」**并存**且不冲突：语境不同——该键是**三钮等宽键行的
  一员**（与同排「添加」「获取模型」同底同按压光感，2026-08-31 两轮指令：先「接入光感、
  跟前两个一样」，再「应该是圆底，跟之前标题栏更多按钮一样，改样式，对齐宽度」，原
  TEXTUAL 版作废），不是行内单图标键；同日的「更多按钮不用加圆底」是发给**密钥行**

## 2. 演进史（各轮拍板原文与缘由）

1. **2026-08-30 形制定稿**：决明拍板「能接官方形状与光感吗，均官方灰底即可」。此前四处行内键
   （ProviderModelsPanel 获取模型/添加、ProviderBalancePanel 套用模板/查询、ProviderConfigPanel
   预设模板 chips）为官方灰底 + 自绘 borderRadius(18/16) 半胶囊 + 手动 fontColor/fontSize——

   头注释 + AGENTS.md 条目。同日决明澄清选项 chips 豁免（§1 表第 4 行）。
2. **2026-09-02 光感化**：决明「为什么这些按钮没有触摸光效和按压形变」——编辑提示词页身份/位置、
   系统提示词页恢复/保存、服务商编辑页（添加 Key/获取模型/添加/head·Body/余额查询/编辑）等按钮

   按压色），后者走 resolvedButton 光感簇。改造 = 行内操作键（含图标钮）全量四件套化（材质 =
   REGULAR 基准 + 按压形变/触点光效 + 官方浅灰配色，随沉浸光感总档〔2026-09-12 分项退役口径，
   退役前随「其他控件」分项〕；无光感档自动回退官方
   灰底）；主操作键（「保存」类）拍板 primary=true 官方强调蓝 + 恒白字（AdjustStageView 同构）；
   「禁自绘」红线不变。同日补全批：AssistantPromptPage「保存」= 主操作键；ModelSettingsPage
   「选择模型/思考强度」与 AssistantSamplingPage「恢复默认」= 次钮四件套（绑定态菜单材质不变）。

   胶囊外层已有 systemMaterial，同一子树最外层只设一次材质）；ModelPickerSheet「使用中/模型数」
   = 徽章背景（非按钮）；ChatAskUserCard 提交回答 / ChatPageContent 重试 = 官方默认按钮（官方

   删除模型 = 红色危险键自绘（cardBg 红字卡形，非灰底批次）。同日关联修复 = 三页按钮条 THIN

   SearchPage/PageShell 标题栏等「组件自身背景」合理载体）。

## 3. 内容区双态（CONTENT_FALLBACK_KEY）速查

- 键定义于 `common/ImmersiveLevel.ets`（默认 true），EntryAbility persistProp（坑17 时机，
  已存用户值优先）；开关 = 「外观显示」页光感面板第四卡，**2026-09-07 更名「光感新规范」**
  （行为等价于原「内容区回退兜底」，设置搜索旧名关键词保留）。
- 内容区非弹窗组件按钮 = `fallbackButton*` 四件套（Material/StateEffect/Bg/Font）：
  开关开 = 官方实底（语义色自动反色）、关 = 透传 resolvedButton* 光感态。
- **分段胶囊例外（SegmentBar 专属，2026-09-07 拍板；2026-09-11 几何统一修订）**：开关开 =
  A 档（背板官方灰阶实色 `app.color.comp_fallback_gray`——零参数官方默认背板为半透明灰、
  吸顶滚过场景可读性差，2026-09-07 晚真机反馈后拍板覆盖为不透明官方灰阶；选中底/字色
  零参数官方默认，不接光感，详见 SegmentBar 头注释速查表首行）；关 = 原光感态（材质 +
  半透明灰选中）。**尺寸 = 两态共用的项目值（32vp 胶囊 / 四周 4vp / 文字边距四向 4，
  2026-09-11 统一）**——开关只切材质与配色（恒等式 4+32+4=40 ⇒ 背板恒 40vp）。
  消费点 = 全项目 15 处 / 12 文件（2026-09-11 实测：AppearancePage/LogPageContent/
  PreferencesPage/UsageStatsPage/CostStatsPage/ProviderPage/ProviderDetailPage/
  ProviderConfigPanel/ModelEditPage/SearchEnginePage/ChatSessionList/ModelPickerSheet，

## 5. 页面顶部光感接入（二级页骨架；2026-09-15 六百零二补）

- **判据一句话**：标题栏的 `GRADIENT_BLUR` 渐变模糊蒙层**要有滚动内容从底下经过才看得见**——蒙层底下只有纯色背景 = 光感空转，真机观感就是「顶部没接沉浸光感」。所以决定观感的不是「页顶有没有光感件」，而是**滚动内容能不能滑进标题栏蒙层背后**。
- **硬规则（新列表页 / 滚动页落笔前过一遍）**：
  1. 滚动容器（`List` / `Scroll`）**铺满整页**（`.height('100%')` 或 `layoutWeight(1)`），其外层包裹容器（`Stack` / `Column`）**禁挂 topPad/bottomPad padding**——包裹层 padding 会缩进其内滚动容器的视口，内容到留白边界即被裁出，与把 padding 直接挂在 `List` 上同病（坑9 复发形态，2026-09-15 附件管理页真机实锤）。
  2. 顶/底留白一律走官方 `contentStartOffset` / `contentEndOffset`（`List`）或**滚动内容内部**的 padding（`Scroll` + 内容 `Column`）。
  3. **悬浮件只许是交互件**（分段胶囊 / 分段条等）——纯信息行（计数 / 合计 / 说明文字）**随内容滚动**（做成滚动容器内的首项），**不做悬浮**：固定信息行与滚上来的卡片观感割裂（2026-09-15 决明真机指令，同日撤销该页合计条悬浮实现；同族九处悬浮件无一例外都是胶囊）。
  4. 悬浮容器的命中按「**含可点子件用 `Transparent`、纯展示用 `None`**」（先例 `SessionMultiselectBar` 头注释口径）——不设档时其矩形内的触摸被拦住，列表顶部既不能滚也不能点。
