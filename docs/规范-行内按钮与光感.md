**四档阶梯（2026-10-24 定，选档时从上往下问）**：本卡收口动作 → 主操作键（实蓝）；推进型但非收口 → 淡彩次级键；中性可逆/工具型 → 行内文字键（灰）；轻动作（折叠/导航/浮层）→ 轻动作文字键或行内图标键（无底）；破坏性 → 危险文字键（灰底红字）。同语义键全站必须同档（测试族/模板族/恢复默认族的档位漂移已随四档笔归一，禁再分叉）。

## 2. 演进史（各轮拍板结论与教训；2026-09-25 精简——判据全保留，过程叙述删，细目按节号查 `docs/变更记录.md`）

## 5. 页面顶部光感接入（二级页骨架；2026-09-15 六百零二补）

- ★ **页顶悬浮胶囊的「原位恢复材质」路线**（2026-09-24 真机实测）：见 §6——胶囊改由标题栏 `bottomBuilder` 承载即得沉浸光感材质，代价 = 各页要接壳参数、几何与穿透口径要重验；产品侧**未立项**。
- **判据一句话**：标题栏的 `GRADIENT_BLUR` 渐变模糊蒙层**要有滚动内容从底下经过才看得见**——蒙层底下只有纯色背景 = 光感空转，真机观感就是「顶部没接沉浸光感」。所以决定观感的不是「页顶有没有光感件」，而是**滚动内容能不能滑进标题栏蒙层背后**。
- **硬规则（新列表页 / 滚动页落笔前过一遍）**：
  1. 滚动容器（`List` / `Scroll`）**铺满整页**（`.height('100%')` 或 `layoutWeight(1)`），其外层包裹容器（`Stack` / `Column`）**禁挂 topPad/bottomPad padding**——包裹层 padding 会缩进其内滚动容器的视口，内容到留白边界即被裁出，与把 padding 直接挂在 `List` 上同病（坑9 复发形态，2026-09-15 附件管理页真机实锤）。
  2. 顶/底留白一律走官方 `contentStartOffset` / `contentEndOffset`（`List`）或**滚动内容内部**的 padding（`Scroll` + 内容 `Column`）。
  3. **悬浮件只许是交互件**（分段胶囊 / 分段条等）——纯信息行（计数 / 合计 / 说明文字）**随内容滚动**（做成滚动容器内的首项），**不做悬浮**：固定信息行与滚上来的卡片观感割裂（2026-09-15 决明真机指令，同日撤销该页合计条悬浮实现；同族九处悬浮件无一例外都是胶囊）。
  4. 悬浮容器的命中按「**含可点子件用 `Transparent`、纯展示用 `None`**」（先例 `SessionMultiselectBar` 头注释口径）——不设档时其矩形内的触摸被拦住，列表顶部既不能滚也不能点。★ **`Transparent` 只放行「空白区」；浮层实体区（本体背板 / 键间隙 / 左右留白）必须自挂点击消费**（空 `onClick`；子键为深层识别器照常优先响应）——实体区无消费方时点击穿透到下层列表（多选态 = 误勾选卡片；2026-10-05 多选批量条真机报障实锤，成因与查证 = 坑96）；反向错误修法 = 把根容器改默认档「求不穿透」= 整屏死区（09-04 事故形态），禁。
- **先例（全仓十处实例，2026-09-15 六百零三核对；★ 2026-09-20 应用内自检全量退役：原列第十处 `SelfCheckPage`〔2026-09-12 四百四十三节报障修复〕随页面删除；★ 2026-09-27 数据同步分段笔 `DataSyncPage` 增为第十处）**：`ProviderPage`（分段胶囊 + `contentStartOffset` 首例）/ `SearchEnginePage` / `ProviderDetailPage` / `SkillEditPage` / `AppearancePage` / `LogPageContent` / `ChatSessionList` / `UsageStatsPage` / `CostStatsPage` / `DataSyncPage`；条状悬浮件范式 = `SessionMultiselectBar`（悬浮无实底容器 + 左右 16）；本页 `AttachmentManagePage`（2026-09-15 六百零二/六百零三/六百零五节：报障修复 → 同构收口 → 合计条改随滚）。

  防后人误改）**：附件查看器页（`components/chat/AttachmentViewerPage.ets`）**两模式均不让内容

## 6. 内容区件挪进标题栏（承载位选型；2026-09-24 真机实测）

- **适用问句**：内容区某个件（分段胶囊 / 分段条 / 搜索框类）想恢复沉浸光感材质 → 官方约束
  下只有「挪进标题栏」这条正路（《沉浸光感简介》「其余组件仅在 Navigation/NavDestination
  标题栏，或横向 Tabs 中 barPosition 为 BarPosition.End 的底部 TabBar 生效」）。
  **凡动此念，先读本节 + 调研卷三第 14 篇**（`docs/归档/调研-归档-03-平台能力与架构.md`）。
- **三个承载位对照（截至 2026-09-24 实证面）**：

| 承载位 | 位置 | 材质 | 依据 |
|---|---|---|---|
| 内容区悬浮（现状） | 标题栏下、随页吸顶 | ❌ 不生效 | 官方生效范围约束（豁免区之外） |
| `stackBuilder` 覆盖层 | 标题栏行内（与标题同行） | ✅ 真机实测 | 本项目先例（`TitleBarKeys` 自绘胶囊 THIN 材质真机验收）+ 09-24 实测 |
| `bottomBuilder` 自定义区 | 标题栏正下方（可与现状位置几乎重合） | ✅ 真机实测 | 09-24 首证；官方《设置自定义区域》明示用途 |

- **落地五条硬约束**（缺一即白干或出坑）：
  1. builder 必须是**组件内 @Builder**（全局 @Builder 被官方 napi 直接调用无视图上下文 →
     闪退，坑30）；`PageShell` 现只暴露 `titleBarStack`（= `stackBuilder`）——要
     `bottomBuilder` 须给壳加参。
  2. 走 `hdsTitleBarOptions(...)` **返回值挂载**（`opts.content.bottomBuilder = {...}`）时，
     `assert-feature-domain` 60 组「覆盖层消费方逐名列出」对账面不受影响（该钉扫的是函数第 5
     参；先例 = 09-24 临时测试页〔该临时件已随验收拆除，形制留在 §7：带经返回值挂载、
     不经函数第 5 参〕）；若改函数签名加参，须同步该组对账清单。
  3. `bottomBuilder` 高按内容实算（官方示例档 56），`showType` 默认 `DIRECTLY_SHOW`
     （另一档 `OVERDRAG_SHOW`）；官方明示自定义节点不得超出标题栏可用空间（否则布局溢出）。
  4. 承载后几何与穿透要重验：现行「胶囊上缘探入蒙层 8vp（`topPad − 8`）+ 列表从胶囊下穿过
     （`contentStartOffset`）」的算式会与标题栏预留带打架（§5 硬规则 1~4 照旧适用）。
  5. **bottomBuilder 唯一形态**（2026-10-31 撤回退拍板：HDS 组件自 API 20 起系统内置、
     本项目 compatibleSdkVersion 26 ≥ 20、canIUse 恒真、回退分支已撤）；`stackBuilder` 与
     `bottomBuilder` 同屏并存本轮显示正常，但独立结论仍属真机项。
- **未决面**：卡内分段胶囊（十余处）与半模态面板内件（`ModelPickerSheet` /
  `MessageCopySheet`）**没有标题栏落点**——只迁页顶那批会让胶囊分两族材质观感，是否接受该
  分叉属产品选择；产品侧迁移**未立项**（前置条件清单 = 调研卷三第 14 篇 §三）。

  胶囊 + 强调蓝字，2026-11-05 两笔后）与内容区族（灰轨道白药丸 + font_primary）各自成族，

  口径（`resolvedUiMaterial` / `SegmentBar` 光感态簇），**新接入点禁自造参数**。
- **官方性口径（2026-09-24 决明追问后立，防「纯官方」一词被两头滥用）**：判「是否纯官方」

  出效果）/ **③绕行度**（有无借未承诺边界、绕过收紧意图）。原「内容区实底双态」与「标题栏
